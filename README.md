# Гараж №67 — заявки на ремонт

Небольшая информационная система автосервиса: клиенты записывают автомобили на ремонт, администратор ведёт заявки и услуги.

**Стек:** Node.js + Express · SQLite (better-sqlite3) · HTML/CSS/JS без фреймворков.

## Запуск

**Через Docker**

```bash
docker compose up --build
```

**Без Docker** (нужен Node.js 18+)

```bash
npm install
npm start
```

Открыть: <http://localhost:3000>

## Доступ администратора

| Email | Пароль |
|---|---|
| `admin@autoservice.local` | `admin123` |

Клиенты регистрируются сами на странице входа. Смените пароль администратора перед публикацией в сеть.

## Возможности

**Клиент:** регистрация и вход · свои автомобили · список услуг · создание заявки · статусы заявок (отмена, пока заявка «Новая»).

**Администратор:** все заявки с контактами клиентов · смена статуса (Новая → В работе → Выполнена / Отменена) · добавление, редактирование, скрытие и удаление услуг.

## Структура

```
server.js        API и работа с базой
public/          интерфейс (index.html, style.css, app.js)
data/            файл базы autoservice.db (создаётся при первом запуске)
Dockerfile, docker-compose.yml
```

## База данных и DBeaver

Файл базы: `data/autoservice.db`. В DBeaver: **Новое подключение → SQLite → выбрать этот файл**.
Таблицы: `users`, `sessions`, `cars`, `services`, `requests`.
Начальные услуги и администратор создаются автоматически. Чтобы начать с чистой базы — остановите сервер и удалите `data/autoservice.db`.

## API

| Метод | Путь | Доступ |
|---|---|---|
| POST | `/api/register`, `/api/login`, `/api/logout` | все |
| GET | `/api/me` | все |
| GET | `/api/services` | вход |
| POST, PUT, DELETE | `/api/services[/:id]` | админ |
| GET, POST, DELETE | `/api/cars[/:id]` | клиент (свои) |
| GET, POST | `/api/requests` | клиент — свои, админ — все |
| PATCH | `/api/requests/:id/status` | админ; клиент — только отмена своей новой заявки |
